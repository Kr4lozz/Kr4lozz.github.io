Privacy Policy

Last updated: October 22, 2026

1. Overview

Videos Creados is a personal tool used only by its owner to publish the owner's own videos to the owner's own TikTok account. It has no other users and does not collect information from the public.

2. Data we access

When the owner authorizes the app with TikTok Login Kit, the app receives an access token and a refresh token for the owner's account, with the scopes user.info.basic, video.upload and video.publish. It does not read or store any other user's data.

3. How data is used and stored

The tokens are used only to upload and publish the owner's videos. They are stored as encrypted secrets in the owner's private GitHub repository. They are not sold, shared or disclosed to third parties.

4. Retention and deletion

Tokens are kept while the integration is in use. The owner can revoke the app's access at any time from TikTok's settings, and delete the stored secrets from GitHub.

Contact: through the owner's GitHub profile, github.com/Kr4lozz.
